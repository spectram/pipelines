# List of template parameter settings for SoFiA
#
# Note that SoFiA's default parameters are actually hard-coded in the
# file Parameter.c, and any changes to this file will have no effect.
# This file can instead be used as a template for setting up your own
# parameter files.
#
# Final pass: the real source-finding/catalog step, run once per combo on the final
# (optionally rebinned, optionally PB-corrected) exported image -- distinctly tuned from the
# masking pass (looser S+C kernels, higher reliability threshold, writes catalog/cubelets/PV
# too). Ported from m2-image-scripts/fincubes/rebinsof.file (origin/HI-dev) -- see
# REFACTOR_PLAN.md's Phase 6 write-up. input.data is patched at runtime by
# hi_sofia.py/cont_sofia.py.
#
# NOTE (deferred, not yet implemented): the prototype's own use of this template expected a
# data-processing step just before this pass -- adding a common beam to the header,
# converting spectral axis units, etc. That step doesn't exist yet; this pass currently runs
# directly on finalize_stage()'s exported FITS. Add that step here (before the sofia() call
# in hi_sofia.py/cont_sofia.py) when it's built.
