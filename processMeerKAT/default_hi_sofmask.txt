# List of template parameter settings for SoFiA
#
# Note that SoFiA's default parameters are actually hard-coded in the
# file Parameter.c, and any changes to this file will have no effect.
# This file can instead be used as a template for setting up your own
# parameter files.
#
# Shared base template for both of sofia_engine.py's SoFiA passes -- the masking pass
# (source-finds on a non-final imaging stage's image to produce the island mask the next
# stage's tclean uses, mask='prev') and the final pass (the real source-finding/catalog
# step, run once per combo on the final exported image). The two passes are ~90% identical;
# where they genuinely differ (S+C kernels, reliability threshold, which output products get
# written), sofia_engine.run_pass() patches this base at runtime via the
# [hi_image]/[cont_image] 'sofia_mask_params'/'sofia_final_params' config overrides -- see
# default_config.txt. input.data/output.directory/output.filename are also patched at
# runtime by hi_sofia.py/cont_sofia.py, regardless of pass.
#
# Ported from m2-image-scripts (origin/HI-dev): m2h0/m2h0sof.file (masking pass) and
# fincubes/rebinsof.file (final pass) -- see REFACTOR_PLAN.md's Phase 6 write-up.
#
# NOTE (deferred, not yet implemented): the prototype's own use of the final pass expected a
# data-processing step just before it -- adding a common beam to the header, converting
# spectral axis units, etc. That step doesn't exist yet; the final pass currently runs
# directly on finalize_stage()'s exported FITS. Add that step here (before the sofia() call
# in hi_sofia.py/cont_sofia.py) when it's built.
